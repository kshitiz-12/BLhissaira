# New B. L. Hissaria Jewellers — React + Tailwind

Premium responsive jewellery website built with Vite, React, Tailwind CSS, Framer Motion and Lucide React.

## Run

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Main files

- `src/main.jsx` — complete page structure, animations, collections and enquiry modal
- `src/index.css` — Tailwind import + luxury theme utilities
- `src/assets/` — supplied jewellery photography and recreated logo mark
- `vite.config.js` — Vite + React + Tailwind v4 plugin

## Replace before launch

1. Add the shop's real phone/WhatsApp number to the enquiry flow.
2. Replace any collection copy with approved brand copy.
3. Connect the enquiry form to WhatsApp, email, CRM or backend API.
4. Add real product inventory/product pages if this becomes an e-commerce store.
